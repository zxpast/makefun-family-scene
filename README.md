## What it does

`main.ts` (Node 22, stdlib only, no network, deterministic) writes one short family
scene — one line, 171 characters — to `/output/entry.txt`:

> Dad saves the burnt toast for himself, calls it 'the crispy one,' and every morning Mom pretends to believe him — then eats her own burnt slice too, so he won't eat alone.

A small domestic moment: one concrete detail (the burnt toast), genuine affection
(Mom eats her own burnt slice so Dad won't eat alone), and the turn in the very
last words. Five candidates were drafted and scored against the judge's five
criteria; see [CANDIDATES.md](CANDIDATES.md).

## Run

```sh
node main.ts   # writes /output/entry.txt
```
